DAV Lab Experiment 1
Experiment Title
Installation and Verification of Python Libraries for Data Analytics and Visualization

Aim
To install, import, and verify the versions of commonly used Python libraries for Data Analytics and Visualization.

Libraries Used
NumPy
SciPy
Pandas
Matplotlib
Seaborn
Plotly
Bokeh
Statsmodels
JupyterLab
Software Requirements
Python
Jupyter Notebook / JupyterLab
NumPy
SciPy
Pandas
Matplotlib
Seaborn
Plotly
Bokeh
Statsmodels
Procedure
Install Python and Jupyter Notebook/JupyterLab.
Install the required Python libraries.
Import the required libraries into the Python program.
Access the version information of each installed library.
Display the installed versions.
Verify that all required libraries are installed correctly.
Program
The complete program is available in the Jupyter Notebook included in this repository.
